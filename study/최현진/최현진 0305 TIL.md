1. 서비스 핵심 기능 및 AI 아키텍처 확정
사용자의 지출 데이터를 단순 나열하는 것이 아니라, 심리적 개입과 데이터 정교화를 거치는 3단계 AI 기능을 정의함.

기능 1: 소비 분석 리포트 (Insight)

날짜별 누적 지출 추이 분석 및 지난달 대비 소비 속도 측정.

또래 집단과의 카테고리별 소비 비율 비교 통계 제공.

기능 2: 지출 해명 챗봇 (Data Refinement)

AI의 오분류나 특수 상황(정산, 장기적 절약 지출 등)에 대해 사용자가 대화로 해명.

Function Calling 기술을 활용하여 해명 내용을 바탕으로 실제 지출 데이터를 수정 반영.

기능 3: AI 팩폭 (Behavior Control)

사용자의 구매 고민 시 리포트 데이터를 근거로 소비를 통제하는 페르소나 기반 피드백.

2. 기술 검토 및 AI 모델 테스트
HuggingFace 로컬 모델 테스트:

Llama-3-8B-Korean-Bllossom 모델을 Colab(T4 GPU) 환경에서 로드 시도.

4비트 양자화(bitsandbytes) 적용에도 불구하고 8B 모델의 메모리 점유로 인한 OutOfMemoryError (OOM) 발생 확인.

환경 최적화 전략:

로컬 서버(WSL) 및 Colab 사양을 고려하여 Gemma-2-2B 등 경량화 모델로 선회하거나 API 방식 도입 검토.

API 전략 수립:

리포트 분석: 추론 능력이 뛰어난 GPT-4o 추천.

해명 챗봇: 속도가 빠르고 멀티모달(영수증 인식 등) 확장성이 좋은 Gemini 1.5 Flash 추천.

AI 팩폭: 가성비와 캐릭터 연기력이 좋은 GPT-4o-mini 추천.
