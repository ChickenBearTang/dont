# AI 소비리포트 POC 계획

## 목표

- `ai` 폴더 안에서 원천데이터 기반 소비리포트 POC를 완성한다.
- 흐름은 `raw 데이터 -> 통계 생성 -> 이상탐지 -> LLM 해설 -> API 응답`으로 고정한다.
- 통계 자료는 사람이 직접 편집하지 않고 코드로만 생성한다.

## 범위

- 사용자 수: 1명
- 기간: 2026-01 ~ 2026-03
- 서비스 형태: FastAPI 단일 서비스
- 분석 방식: 규칙 기반 집계/이상탐지 + Gemini 해설
- 연동 범위: `ai` 서비스 단독 완성까지

## 작업 순서

1. 문서와 데이터 계약 고정
2. raw 데이터 정비 및 정합성 맞추기
3. generated 리포트 생성 파이프라인 구현
4. 이상탐지 로직 구현
5. Gemini 기반 해설 추가
6. API 엔드포인트 추가
7. 테스트 및 회귀 검증

## 운영 원칙

- 새 기능은 작업 단위별로 커밋한다.
- 생성 산출물은 raw 데이터 기준으로 언제든 재생성 가능해야 한다.
- 한글 데이터는 UTF-8로 저장한다.
